# Fairview Bedding – Free E-commerce Website

This is a lightweight, mobile-friendly static e-commerce storefront.

## Included
- Responsive home page
- Product catalogue
- Category filters
- Shopping cart
- WhatsApp checkout
- Fairview Bedding branding
- No paid hosting required

## Free deployment
### GitHub Pages
1. Create a free GitHub account.
2. Create a public repository named `fairview-bedding`.
3. Upload `index.html`, `style.css`, and `script.js`.
4. Open Settings → Pages → Deploy from branch → main → /(root).
5. Your free address will look like:
   `https://YOUR-USERNAME.github.io/fairview-bedding/`

### Netlify
Drag the project folder into Netlify's deploy area. Netlify provides a free `*.netlify.app` address.

## Important
This version uses WhatsApp checkout rather than a paid payment gateway. Product prices and WhatsApp number should be replaced with your actual business details before launch.
